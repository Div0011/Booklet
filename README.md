## How to Read the Booklet

### 1. Interactive Reader (`reader.html` / `index.html`)
For the best reading and study experience, open `reader.html` or `index.html` in your browser:
* **Running a local HTTP server:** `python3 -m http.server 8000` -> Open `http://localhost:8000/reader.html`.
* **Direct File Access:** Open `reader.html` directly in your browser and select the `booklet` directory.

#### Key Features:
- **Interactive Flashcard Practice Mode:** Test yourself on Section 8 interview and exam questions across all 52 chapters.
- **Progress Tracking:** Check off chapters as you study with persistent localStorage sync.
- **Glassmorphic Theme:** Optimized dark/light modes designed for extended reading sessions.

### 2. Compiled Master Documents (`booklet.md` & `Complete_Interview_Handbook_2025.docx`)
- **`booklet.md`:** 2.4 MB complete consolidated markdown document containing all 52 chapters with a hyperlinked Table of Contents.
- **`Complete_Interview_Handbook_2025.docx`:** Professional Microsoft Word handbook containing all 10 Parts and 48 Chapters with rich typography, code styling, and formatted formulas.
